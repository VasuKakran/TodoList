# My Todo App

A simple and user-friendly todo application built with React. This app allows users to add, edit, delete, and mark tasks as completed to help manage daily activities efficiently.

## Features

- Add new todo items
- Edit existing todo items
- Delete todo items
- Mark todo items as completed
- Responsive and clean user interface

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/VasuKakran/TodoList
   ```
2. Navigate to the project directory:
   ```bash
   cd my-todo-app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Open your browser and go to `http://localhost:3000` to see the app in action.

## Usage

- Use the input field to add new tasks.
- Click on a task to mark it as completed.
- Use the edit button to modify a task.
- Use the delete button to remove a task.
